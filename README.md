# Inventory Management System (CSC 1102 Practical Exam Project - Group 26)

A Java Swing application for managing products, suppliers and stock levels.

Repository: https://github.com/matthewchelan-del/Inventory_Management_System.git

## Run
```
cd src
javac *.java
java Main
```
Or open the `src` folder in any Java IDE and run `Main.java`.

## Files
- `Main.java` - entry point (group details in the header comment)
- `Product.java`, `Supplier.java` - entity classes
- `Inventory.java` - arrays + business logic
- `InventoryGUI.java` - Swing interface
- `Inventory_Management_System_Report.pdf` - project document
